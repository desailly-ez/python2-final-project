# PTC Breweries App

## Group Members


## Description

The PTC Breweries App is a simple web application developed using Python and Flask. The application retrieves brewery data from the Open Brewery DB API and displays it in a table format. Users can sort and filter the breweries by country or brewery type.

## Features

- Retrieve brewery data from the Open Brewery DB API
- Display brewery information in a table
- Sort breweries by name in ascending order
- Filter breweries by country
- Filter breweries by brewery type
- Use generator functions for data processing
